# Рукописный или печатный текст

Практическая работа по предмету «Интеллектуальные системы и технологии».
Две настоящие мультимодальные нейросети Qwen2-VL 2B и Qwen3-VL 2B сравниваются на
одних изображениях. Вычисления идут на компьютере. Подписка и токен не нужны.

## Скачать с GitHub и запустить на Windows

1. Откройте [релиз v2.0.0](https://github.com/Sailats/3prac/releases/tag/v2.0.0)
   и скачайте **TextType_Source.zip**. Также можно выбрать **Code → Download ZIP**.
2. Полностью распакуйте архив в отдельную папку.
3. Дважды нажмите **Start_Windows.bat** и оставьте окно открытым.
4. При первом запуске дождитесь установки Python, библиотек и двух моделей.
   Нужен интернет; подписка, токен Hugging Face и отдельная установка Python не нужны.
5. Откроется программа: **http://127.0.0.1:8765**.
   Выберите пример или своё фото и нажмите «Сравнить две модели».

После первой установки можно работать без интернета. Веса автоматически
скачиваются из официальных открытых репозиториев и подготавливаются в NF4.
В Git они не входят. Для первой установки желательно иметь **30 ГБ свободного
места**, Windows 10/11 x64 и 16 ГБ RAM. На этом ПК проверена RTX 2060 SUPER 8 ГБ.
Первое скачивание и подготовка моделей занимают время; окно показывает этапы.
Если видеокарта недоступна, используйте **Start_CPU.bat** — он работает медленнее.

Исходники, 50 изображений, результаты, отчёт и текст для защиты включены в репозиторий.

## Если у вас есть полный переносимый архив

**TextType_Portable_Windows.zip** (около 7,75 ГБ) был подготовлен и проверен
отдельно. Он содержит Python, библиотеки и веса; в релиз GitHub этот большой
архив не загружен. Для версии с GitHub используйте инструкцию выше.

1. Полностью распакуйте **TextType_Portable_Windows.zip** в обычную папку,
   например `G:\TextType`. Не запускайте файлы прямо внутри ZIP.
2. Дважды нажмите **Start_Windows.bat**.
3. Оставьте появившееся окно открытым. Откроется страница программы.
   Если не открылась: перейдите в браузере на **http://127.0.0.1:8765**.
4. Выберите фотографию или готовый пример и нажмите «Сравнить две модели».
5. Для завершения закройте окно запуска.

Полный переносимый архив содержит Python, библиотеки и обе модели. Интернет
для него не требуется. На NVIDIA используется видеокарта; на других ПК — процессор.
Если с видеокартой возникла ошибка, закройте программу и откройте **Start_CPU.bat**.

Нужны Windows 10/11 x64, желательно 16 ГБ оперативной памяти и 20 ГБ свободного
места для архива и распаковки. Проверена RTX 2060 SUPER с 8 ГБ видеопамяти.
На процессоре ответ может занимать заметно больше времени.

**Маленький архив TextType_Source.zip** содержит исходники, изображения и
результаты, но не тяжёлые модели и библиотеки. При его первом запуске установщик
скачает отдельный Python 3.12, библиотеки и модели. Интернет и несколько ГБ трафика
нужны только при установке. Системный Python, даже версии 3.14, не используется.

## Что показать преподавателю

- Загрузку своего изображения и ответы двух нейросетей с временем.
- Кнопку «Запустить эксперимент»: обработку 40 тестовых изображений.
- Сравнительную таблицу, матрицы ошибок и сохранённые JSON/CSV.
- `docs/Отчет.html` — готовый отчёт с фактическими результатами.
- `docs/Защита.txt` — короткое выступление и ответы на вопросы.
- Кнопку «Как устроен проект» в программе.

**Соответствие слайду:** исходное задание, судя по обсуждению, требует LLM через
Hugging Face Inference Providers. Здесь две VLM с Hugging Face запущены локально,
чтобы избежать платных запросов. Это изменение способа запуска нужно обозначить
преподавателю, если он требует именно провайдеров.

## Полученные результаты

Повторное сравнение на 40 изображениях (20 рукописных и 20 печатных):

| Модель | Верно | Accuracy | F1 macro | Среднее время после прогрева |
|---|---:|---:|---:|---:|
| Qwen2-VL 2B NF4 | 37/40 | 92,5% | 94,7% | 0,38 с |
| Qwen3-VL 2B NF4 | 40/40 | 100% | 100% | 0,34 с |

У Qwen2 два отказа и одна ошибка класса; сбоев исполнения нет у обеих моделей.
На 10 dev-примерах обе дали 10/10. Это малая уже использованная выборка;
100% на ней не гарантирует безошибочную работу на новых фото. Разные инструкции
выбраны по dev и зафиксированы до нового прогона test. Старые результаты SmolVLM
сохранены в истории. Протокол: `results/latest_test.json`.

## Как устроен код

| Файл | Что делает |
|---|---|
| `predict.py` | Открывает фото, загружает нейросети, выполняет генерацию, проверяет ответ |
| `evaluate.py` | Читает разметку, запускает одинаковые изображения, считает метрики |
| `app.py` | Локальный HTTP-сервер и фоновые задачи |
| `web/` | Русский интерфейс без сборки и внешних ресурсов |
| `download_models.py` | Скачивает общедоступные веса без токена |
| `quantize_models.py` | Готовит NF4-веса из официальных исходных весов |
| `setup_windows.ps1` | Автоматическая установка и запуск Windows |
| `tools/prepare_data.py` | Воспроизводит отбор исходных изображений |
| `tests/` | Проверяет метрики, ввод, разметку и сервер без запуска нейросетей |

Фактический вызов нейросети: `model.generate(...)` в `predict.py`.
Обучения в проекте нет: используются предобученные модели в режиме zero-shot.
Имена файлов, папки и правильные ответы не попадают во вход модели.

## Данные и эксперимент

Включены **50 реальных фрагментов** фотографий и сканов из открытого набора
UkrainianCatholicUniversity/rukopys, лицензия CC BY 4.0. Это фрагменты строк и
заголовков, а не 50 полноразмерных страниц. До эксперимента они проверены визуально.

- `dev`: 5 рукописных + 5 печатных; проверка программы и инструкции.
- `test`: 20 рукописных + 20 печатных; итоговое сравнение.
- Каждый фрагмент взят из отдельного исходного документа.
- Файлы и разметка: `data/images/`, `data/manifest.csv`.
- Источники, координаты, лицензия, ревизия набора, исключения: `data/provenance.json`.
- Контактные листы: `data/contact_handwritten.jpg` и `data/contact_printed.jpg`.

Идентичность автора почерка в наборе не установлена: разные документы могут быть
написаны одним человеком. Нельзя утверждать, что тест проверяет новых авторов.
Состав выборки небольшой, встречаются узкие/размытые фрагменты и водяной знак.

Обе модели получают одно и то же изображение с максимальной стороной 1024 пикселя,
английскую инструкцию для своей модели и ограничение 12 новых токенов; генерация без
случайного сэмплирования. Перед замером выполняется прогрев на одном dev-примере.
Порядок моделей чередуется. Время включает подготовку входа и генерацию,
но исключает первоначальную загрузку и прогрев в эксперименте.

Допустимые ответы: `handwritten`, `printed`, `unknown`. Другой ответ — `invalid`.
Ошибка исполнения — `error`. В Accuracy отказы и сбои остаются в знаменателе.
Precision/Recall/F1 в интерфейсе относятся к рукописному классу; F1 macro — среднее
F1 двух классов. Полный протокол содержит показатели обоих классов.

Результаты сохраняются в `results/`. `latest_test.json` — последний прогон,
файлы с датой — история. В JSON записаны инструкция, параметры, версии, хеши
набора инструкций и разметки, сырые ответы и время каждого изображения.

## Команды для желающих разобраться

В переносимом архиве из папки проекта:

```text
.runtime\python.exe -m unittest discover -s tests -v
.runtime\python.exe evaluate.py --split dev
.runtime\python.exe evaluate.py --split test
.runtime\python.exe app.py --device cpu
```

Проверка установщика без открытия интерфейса:

```text
powershell -NoProfile -ExecutionPolicy Bypass -File setup_windows.ps1 -InstallOnly -Check
```

Mac/Linux: установите Python 3.11–3.12, создайте venv, установите Torch 2.7.1
для вашей платформы и `pip install -r requirements.txt`, затем
`python download_models.py` и `python app.py`. Этот вариант не проверялся:
проверена Windows на компьютере пользователя.

## Если не запускается

- **Открыли файл внутри ZIP:** сначала извлеките весь архив в папку.
- **Окно закрывается с ошибкой:** запустите Start_Windows.bat и прочитайте текст;
  при ошибке там предусмотрена пауза.
- **Адрес уже занят:** закройте предыдущую запущенную копию. Для ручного запуска
  используйте `.runtime\python.exe app.py --port 8766`.
- **Ошибка CUDA или памяти видеокарты:** закройте программу и запустите Start_CPU.bat.
- **Долго думает при первом фото:** модели загружаются в память. Дождитесь результата.
- **Модель дала неверный ответ:** это реальный результат; проверьте качество кадра.
  Для пустых или смешанных изображений корректное поведение не гарантируется.
- **Windows просит разрешить запуск скачанного файла:** запускайте только архив,
  который вы получили здесь и содержимое которого проверили.

## Изменения версии 2

SmolVLM заменена на Qwen3-VL 2B. Линейные слои декодера обеих моделей сжаты до NF4 с двойным квантованием; визуальный энкодер и выходной слой оставлены в FP16. Обучения и использования тестовой разметки при сжатии нет. Веса обеих моделей подготовлены из официальных ревизий, происхождение и хеши находятся рядом с весами.

Эти 40 изображений уже участвовали в предыдущем выборе моделей. Обновлённые цифры показывают повторное учебное сравнение, для независимой проверки нужна новая выборка. По dev выбраны разные формулировки: подробная для Qwen2-VL, короткая для Qwen3-VL. Задача и классы одинаковы. Сравниваются две настроенные связки, поэтому нельзя приписывать разницу только самим моделям. Обе инструкции сохранены в протоколе и отчёте. Разметка и состав изображений не менялись.
