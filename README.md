# Практическая работа 3: рукописный или печатный текст

Локальное приложение с двумя настоящими бесплатными VLM: **Qwen2-VL 2B** и
**Qwen3-VL 2B**. Задача — определить тип текста на изображении. Программа не
переписывает слова с фото и не обучает нейросеть с нуля.

## Простой запуск Windows

1. Скачайте **TextType_Source.zip** из [релиза v3.0.0](https://github.com/Sailats/3prac/releases/tag/v3.0.0).
   Или выберите **Code → Download ZIP**.
2. Полностью распакуйте архив в отдельную папку.
3. Дважды нажмите **Start_Windows.bat**, оставьте окно открытым и дождитесь запуска.
4. Если страница не открылась сама: **http://127.0.0.1:8765**.
5. Выберите фото или готовый пример и нажмите «Сравнить две модели».

Для исходников первая установка требует интернета и примерно 30 ГБ свободного
места: автоматически подготавливаются отдельный Python, библиотеки и открытые
веса. Подписка Hugging Face и токен не нужны. После установки можно работать
без интернета. Системный Python не заменяется.

Отдельно подготовлен **TextType_Portable_Windows.zip** с готовой средой и весами.
Он запускается без установки через сеть; большой полный архив в GitHub не входит.
Проверены Windows x64, 16 ГБ RAM, RTX 2060 SUPER 8 ГБ. Резервный запуск на
процессоре — **Start_CPU.bat**, он заметно медленнее.

## Что упрощено в версии 3

Основной код — **три Python-файла**:

| Файл | Ответственность |
|---|---|
| `app.py` | Страница и простые HTTP-маршруты Flask |
| `predict.py` | Подготовка изображения, загрузка двух VLM и получение ответов |
| `evaluate.py` | Проверка 40 изображений, метрики и сохранение JSON/CSV |

Сервер сокращён со 193 до 108 строк. Самописные HTTP-обработчики, JobManager,
вложенные фоновые операции и опрос `/api/status` удалены. Теперь запрос сразу
возвращает результат; браузер ждёт его через `await fetch` и остаётся отзывчивым.
Сервер запускается в одном потоке, поэтому вычисления не перекрываются.

Скачивание и квантование вынесены в `support/`. Пользователю не нужно запускать
эти файлы вручную. Сами модели, инструкции, картинки и правила оценки сохранены.

## Что показать на защите

- Печатный и рукописный примеры, затем своё чёткое фото с одним типом текста.
- Исходные ответы в карточках моделей и время обработки.
- Кнопку «Запустить эксперимент», итоговую таблицу и матрицы ошибок.
- Реальный неудачный пример Qwen2 и соответствующий ответ Qwen3.
- Строку `model.generate(...)` в `predict.py`.
- Отчёт и скриншоты в `docs/`; короткие пояснения к коду в `docs/Код_для_защиты.txt`.

## Данные и честное сравнение

50 реальных фрагментов из [rukopys](https://huggingface.co/datasets/UkrainianCatholicUniversity/rukopys),
Ukrainian Catholic University и участники набора, CC BY 4.0:

- 10 dev: 5 рукописных и 5 печатных для проверки формулировок.
- 40 test: 20 рукописных и 20 печатных для сравнительного эксперимента.
- 50 разных исходных документов; идентичность авторов почерка неизвестна.
- Разметка и SHA256: `data/manifest.csv`; происхождение и координаты: `data/provenance.json`.

Модели получают только пиксели и инструкцию, без имени файла и правильной метки.
Формулировки выбраны отдельно на dev: подробная для Qwen2, короткая для Qwen3.
Сравниваются две настроенные связки, а не только архитектуры при идентичном входе.

Эти 40 изображений использовались ранее; новый прогон — повторное учебное сравнение.
Для независимой оценки нужны новые данные. 100% на такой выборке не гарантирует
безошибочную работу на новых фото. Пустые и смешанные кадры отдельно не оценивались.

## Результаты

Полный актуальный протокол: `results/latest_test.json`. JSON/CSV с датой сохраняют
историю, сырые ответы, настройки и время. Повторная проверка версии 3 дала:

| Модель | Верно | Accuracy | F1 macro | Среднее время |
|---|---:|---:|---:|---:|
| Qwen2-VL 2B NF4 | 37/40 | 92,5% | 94,7% | 0,35 с |
| Qwen3-VL 2B NF4 | 40/40 | 100% | 100% | 0,30 с |

У Qwen2 два отказа и одна ошибка класса. Неверных форматов и технических сбоев нет.
Протокол новой версии: `test_20261024_160032.json`.

`unknown`, `invalid` и `error` остаются в знаменателе Accuracy. Coverage показывает
долю допустимых классов; Precision/Recall/F1 на экране относятся к рукописному
классу, F1 macro — среднее двух классов. Загрузка и прогрев исключаются из
сравнительного времени; открытие исходного файла выполняется до замера predict.

## Служебные файлы

| Каталог / файл | Назначение |
|---|---|
| `web/` | Интерфейс без npm и сборки |
| `support/download_models.py` | Проверка файлов и загрузка официальных закреплённых ревизий |
| `support/quantize_models.py` | Подготовка NF4; visual и lm_head сохраняются в FP16 |
| `tools/prepare_data.py` | Первичная подготовка набора; для обычного запуска не нужен |
| `tools/build_report.py` | HTML-отчёт и речь из последнего JSON |
| `tools/package_project.py` | Source и Portable архивы с CRC/SHA256 |
| `tests/` | Проверки ввода, метрик, данных, файлов моделей и прямого API |

Обучения и использования тестовой разметки при квантовании нет. NF4-веса подготовлены
из официальных Qwen2/Qwen3; происхождение и хеши сохраняются рядом с моделями.

## Проверка и ручной запуск

Из распакованной папки с готовой средой:

```text
.runtime\python.exe -m unittest discover -s tests -v
.runtime\python.exe evaluate.py --split test
.runtime\python.exe app.py --no-browser
.runtime\python.exe app.py --device cpu
```

Установщик без открытия программы:

```text
powershell -NoProfile -ExecutionPolicy Bypass -File setup_windows.ps1 -InstallOnly -Check
```

Закройте окно запуска, чтобы завершить работу. При занятом адресе закройте
предыдущую копию либо задайте `app.py --port 8766`. Первое фото после запуска
обрабатывается дольше из-за загрузки моделей.
