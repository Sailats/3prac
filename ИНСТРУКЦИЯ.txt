КАК ЗАПУСТИТЬ ПРАКТИЧЕСКУЮ РАБОТУ С GITHUB

1. Скачайте TextType_Source.zip из релиза:
   https://github.com/Sailats/3prac/releases/tag/v2.0.0
   Или откройте Code → Download ZIP на странице репозитория.

2. Полностью распакуйте архив в отдельную папку.
   Нужны Windows 10/11 x64, желательно 16 ГБ RAM и 30 ГБ свободного места.

3. Дважды нажмите Start_Windows.bat и оставьте окно открытым.
   Первый запуск скачивает отдельный Python, библиотеки и две бесплатные модели.
   Нужен интернет. Покупать подписку, вводить токен и ставить Python вручную не нужно.
   Дождитесь завершения установки и подготовки моделей.

4. Откроется http://127.0.0.1:8765 в браузере.
   Выберите готовый пример или своё фото и нажмите «Сравнить две модели».
   При первом обращении подождите загрузки моделей в память.

5. При следующих запусках используйте тот же Start_Windows.bat.
   После полной первой установки интернет не нужен.
   Чтобы выключить программу, закройте окно запуска.

ЕСЛИ ОШИБКА ВИДЕОКАРТЫ
Закройте программу и запустите Start_CPU.bat. На процессоре работает медленнее.

ЧТО ПОКАЗАТЬ НА ЗАЩИТЕ
Готовый рукописный и печатный примеры, затем своё чёткое фото с одним типом текста.
Сохранённые результаты и матрицы ошибок уже доступны в программе.
«Запустить эксперимент» повторяет 80 вызовов: две модели × 40 изображений.

docs\Отчет.html — отчёт, открывается браузером.
docs\Защита.txt — выступление и ответы на вопросы.
README.md — описание кода, данных, запуска и ограничений.
results\latest_test.json — сырые ответы и параметры последнего сравнения.

Qwen2-VL 2B: 37/40 (92,5%), Qwen3-VL 2B: 40/40 (100%).
Это повторная проверка на небольшой учебной выборке, не гарантия на любых фото.
Задача — определение типа текста (рукописный/печатный), не переписывание слов.

В GitHub включены исходники, изображения и результаты. Тяжёлые веса скачиваются
при установке. Полный автономный TextType_Portable_Windows.zip был подготовлен
отдельно и в релиз GitHub не включён; если он у вас есть, распакуйте его и запустите
Start_Windows.bat — установка через интернет для него не требуется.

ВАЖНО ДЛЯ ЗАЩИТЫ
В обсуждении задания указаны Hugging Face Inference Providers.
Здесь две модели с Hugging Face запускаются локально бесплатно.
Если преподаватель требует строго облачных провайдеров, обозначьте эту замену.
